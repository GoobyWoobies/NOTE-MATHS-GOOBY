# 📐 Mathématiques — Notes de cours (Algèbre linéaire 1)

Bienvenue ! Ces notes reprennent le cours d'**Algèbre linéaire 1** (HEIA-FR, filière Informatique) de façon claire, progressive et illustrée d'exemples tirés des anciens tests.

## Comment est organisé le cours ?

| Partie | Contenu | Point d'entrée |

## Comment lire ces pages ?

Chaque chapitre suit le même ordre : **Objectifs → Prérequis → Définitions → Intuition → Propriétés → Marche à suivre → Exemples → Pièges → Exercices → Liens avec les évaluations**.

- `⚠` **Attention** : une erreur classique à éviter.
- `↳` **Donc** : la conséquence de la ligne précédente.
- **Ex :** une application pas à pas, avec des valeurs.
- Les indices et les solutions des exercices sont **repliés** : essaie d'abord seul.

## Notation utilisée

Les formules sont écrites en LaTeX : $$x^2 + y^2 = 1$$ pour une formule dans le texte, et

$$
\sin^2(\alpha) + \cos^2(\alpha) = 1
$$

pour une formule mise en valeur.
