# Méthodes

## Module 1 — Rappels de trigonométrie

### 1. Géométrie du triangle

| Je connais… | Je cherche… | Outil |
| --- | --- | --- |
| 2 angles | le 3ᵉ angle | $$\alpha + \beta + \gamma = 180^\circ$$ |
| triangle rectangle + 2 côtés | le 3ᵉ côté | Pythagore |
| 3 côtés | est-il rectangle ? | réciproque de Pythagore (plus grand côté = `hyp`) |
| droites parallèles + 2 côtés correspondants | une autre longueur | Thalès (rapport $$k$$) |
| égalités de côtés / angles | triangles isométriques ? | CCC / ACA / CAC |
| demi-cercle + 2 côtés | 3ᵉ côté, hauteur $$h$$ | angle droit en $$D$$ → Pythagore → triangles semblables |

**Pythagore :** rectangle ? → repérer `hyp` → $$\text{hyp}^2 = \text{côté}_1^2 + \text{côté}_2^2$$ → racine **positive**.

**Thalès :** parallèles ? → petit / grand triangle → calculer $$k$$ → rapports **dans le même ordre**.

**Isométrie :** lister les égalités → CCC, ACA (angles **aux extrémités** du côté) ou CAC (angle **entre** les côtés) → conclure.

→ Détails : [chapitre 1](Trigonometrie/01-geometrie-du-triangle.md)

**TE « Triangle & Co. » (Ex. 1 de chaque TE F-1) :** chercher les triangles **rectangles** (demi-cercle, hauteur) → Pythagore → $$h$$ par triangles semblables → angles avec arcsin / loi des sinus (chapitres 3 à 5), ⚠ angle obtus = $$\pi - \beta_0$$ → calculs explicites, 2 chiffres après la virgule.

### 2. Angles

| Je connais… | Je cherche… | Outil |
| --- | --- | --- |
| angle en ° | angle en rad | $$\times \frac{\pi}{180}$$, puis simplifier |
| degrés avec virgule | DMS | partie décimale $$\times 60$$ (deux fois) |
| $$r$$ et $$\alpha$$ | arc, secteur | $$\alpha$$ en rad → $$L = r\alpha$$, $$A = \frac{r^2\alpha}{2}$$ |
| arc vu **depuis le cercle** | rayon | angle au centre = 2 × angle inscrit → $$r = \frac{L}{\alpha}$$ |
| $$v$$ et $$r$$ | tours/s | $$f = \frac{v}{2\pi r}$$ |
| $$v$$ et tours/s | rayon | $$r = \frac{v}{2\pi f}$$ |

**« Lapins crétins » :** unités SI (km/h ÷ 3,6 ; diamètre ÷ 2) → même $$v$$ pour les roues → $$v = 2\pi f r$$ → commenter.

**Aiguilles de montre :** $$\omega_M = 6^\circ$$/min, $$\omega_H = 0{,}5^\circ$$/min → position de chaque aiguille depuis midi → écart. Sens horaire → $$\omega < 0$$.
