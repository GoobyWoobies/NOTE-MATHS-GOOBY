# 5. Les racines

## La racine carrée

Le symbole $\sqrt{\ \ }$ signifie **« racine carrée positive de »**.

$$x = \sqrt{a} \quad\text{signifie}\quad x^2 = a \ \text{ et }\ x \geq 0$$

Comme $a = x^2 \geq 0$, le symbole $\sqrt{a}$ n'a un sens que lorsque $a \geq 0$.

✏️ $\sqrt{9} = 3$ (et **pas** $\pm 3$ : la racine est toujours positive).

## Deux règles avec les racines carrées

Pour $a \geq 0$ et $b > 0$ :

$$\sqrt{a\,b} = \sqrt{a}\,\sqrt{b} \qquad\qquad \sqrt{\frac{a}{b}} = \frac{\sqrt{a}}{\sqrt{b}}$$

✏️ $\sqrt{50} = \sqrt{25 \times 2} = 5\sqrt{2}$

> ⚠️ **Erreur classique** : $\sqrt{a+b} \neq \sqrt{a} + \sqrt{b}$.
> Par exemple $\sqrt{9+16} = \sqrt{25} = 5$, mais $\sqrt{9}+\sqrt{16} = 3+4 = 7$.

## Les racines $n$-ièmes

Si $n$ est un entier positif :

$$x = \sqrt[n]{a} \quad\text{signifie}\quad x^n = a$$

- Si $n$ est **pair**, alors $a \geq 0$ et $x \geq 0$.
- Si $n$ est **impair**, $a$ peut être négatif : $\sqrt[3]{-8} = -2$ car $(-2)^3 = -8$.

## Lien avec les puissances

Si $a > 0$ :

$$a^{\frac{p}{q}} = \sqrt[q]{a^{p}}$$

✏️ **Exemple avec un nombre réel** : $8^{\frac{2}{3}} = \sqrt[3]{8^2} = \sqrt[3]{64} = 4$.
On peut aussi calculer d'abord la racine : $\left(\sqrt[3]{8}\right)^2 = 2^2 = 4$.

> 🔗 La racine carrée d'un carré fait apparaître la **valeur absolue** : voir le [chapitre suivant](06-valeur-absolue.md).
