# Formulaire

## Module 1 — Rappels de trigonométrie

### 1. Géométrie du triangle

| Formule | Condition |
| --- | --- |
| $$\alpha + \beta + \gamma = 180^\circ$$ | tout triangle |
| $$a^2 + b^2 = c^2$$ | triangle rectangle en $$C$$ ($$c$$ = `hyp`) |
| $$k = \frac{\lvert AD \rvert}{\lvert AB \rvert} = \frac{\lvert AE \rvert}{\lvert AC \rvert} = \frac{\lvert DE \rvert}{\lvert BC \rvert}$$ | Thalès, $$(DE) \parallel (BC)$$ |
| CCC, ACA, CAC ⟹ $$\triangle ABC \cong \triangle A'B'C'$$ | un seul critère suffit |
| $$\alpha + \beta + \gamma = \pi$$ | même chose en radians (TE) |
| deux angles côte à côte sur une droite : somme $$180^\circ$$ | angles supplémentaires |
| $$[AC]$$ diamètre, $$D$$ sur le demi-cercle ⟹ angle droit en $$D$$ | « l'arc $$\widehat{ADC}$$ est un demi-cercle » |
| hauteur sur l'hypoténuse : $$h = \frac{\text{côté}_1 \cdot \text{côté}_2}{\text{hyp}}$$ | triangles semblables (TE « Triangle & Co. ») |

Notation : côté $$a$$ en face de $$A$$ (angle $$\alpha$$), $$b$$ en face de $$B$$ ($$\beta$$), $$c$$ en face de $$C$$ ($$\gamma$$).

### 2. Angles

| Formule | Condition |
| --- | --- |
| $$360^\circ = 2\pi \text{ rad} = 400 \text{ gon}$$ ; $$180^\circ = \pi$$ | conversions |
| $$\alpha_{\text{rad}} = \alpha_{\text{deg}} \cdot \frac{\pi}{180}$$ | degrés → radians |
| $$1^\circ = 60'$$ ; $$1' = 60''$$ | degrés-minutes-secondes |
| $$\alpha = \frac{L}{r}$$ | définition du radian |
| $$L = r\alpha$$ ; $$A = \frac{r^2\alpha}{2} = \frac{rL}{2}$$ | $$\alpha$$ en **radians** |
| $$\omega = \frac{\Delta\theta}{\Delta t} = 2\pi f = \frac{2\pi}{T}$$ | vitesse angulaire (rad/s) |
| $$v = r\omega$$ | vitesse linéaire |
| $$\omega_1 r_1 = \omega_2 r_2$$ | transmission (même courroie) |
| angle au centre $$= 2 \times$$ angle inscrit | même arc |
