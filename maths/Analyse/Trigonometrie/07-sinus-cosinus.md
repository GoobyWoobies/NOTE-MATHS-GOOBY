# 7. Sinus, cosinus et angles remarquables

## Définition sur le cercle trigonométrique

Pour un angle $\alpha$, le point $P$ du cercle a pour coordonnées $(x, y)$ et :

$$\cos\alpha = \text{abscisse } x \qquad\qquad \sin\alpha = \text{ordonnée } y$$

> 💡 **Moyen mnémotechnique** : **C**osinus → **C**ôté (horizontal, $x$). Sinus → l'autre (vertical, $y$).

Comme le cercle est de rayon $1$, on a toujours $-1 \leq \sin\alpha \leq 1$ et $-1 \leq \cos\alpha \leq 1$.

## Dans un triangle rectangle

$$\sin\alpha = \frac{\text{côté opposé}}{\text{hypoténuse}} \qquad\qquad \cos\alpha = \frac{\text{côté adjacent}}{\text{hypoténuse}}$$

## Relation fondamentale

Le cercle a un **rayon de $1$**, donc $x^2 + y^2 = 1$, d'où :

$$\sin^2\alpha + \cos^2\alpha = 1$$

✏️ **Exemple** : $\cos\alpha = 0{,}6$ avec $\alpha$ dans le quadrant I.

$\sin^2\alpha = 1 - 0{,}36 = 0{,}64$, donc $\sin\alpha = 0{,}8$ (positif dans le quadrant I).

## Angles remarquables

| Angle | $0^\circ$ | $30^\circ$ | $45^\circ$ | $60^\circ$ | $90^\circ$ |
| --- | :---: | :---: | :---: | :---: | :---: |
| **Radians** | $0$ | $\frac{\pi}{6}$ | $\frac{\pi}{4}$ | $\frac{\pi}{3}$ | $\frac{\pi}{2}$ |
| $\sin$ | $0$ | $\frac{1}{2}$ | $\frac{\sqrt{2}}{2}$ | $\frac{\sqrt{3}}{2}$ | $1$ |
| $\cos$ | $1$ | $\frac{\sqrt{3}}{2}$ | $\frac{\sqrt{2}}{2}$ | $\frac{1}{2}$ | $0$ |

> 💡 **Astuce pour ne pas apprendre par cœur** : pour $\sin$, écris $\frac{\sqrt{0}}{2},\ \frac{\sqrt{1}}{2},\ \frac{\sqrt{2}}{2},\ \frac{\sqrt{3}}{2},\ \frac{\sqrt{4}}{2}$ (ce qui donne $0,\ \frac12,\ \frac{\sqrt2}{2},\ \frac{\sqrt3}{2},\ 1$). Pour $\cos$, on lit la même ligne **à l'envers**.

**Vérification** avec $30^\circ$ : $\left(\frac{1}{2}\right)^2 + \left(\frac{\sqrt{3}}{2}\right)^2 = \frac{1}{4} + \frac{3}{4} = 1$ ✅

## Signes selon le quadrant

Le plan est découpé en 4 **quadrants**, numérotés dans le sens inverse des aiguilles d'une montre.

| Quadrant | Angle | $\sin$ (haut/bas) | $\cos$ (droite/gauche) |
| --- | --- | :---: | :---: |
| **I** | de $0$ à $\frac{\pi}{2}$ | $+$ | $+$ |
| **II** | de $\frac{\pi}{2}$ à $\pi$ | $+$ | $-$ |
| **III** | de $\pi$ à $\frac{3\pi}{2}$ | $-$ | $-$ |
| **IV** | de $\frac{3\pi}{2}$ à $2\pi$ | $-$ | $+$ |

> 💡 **À retenir** : le **sinus** est positif quand le point est **en haut** ($y>0$), le **cosinus** est positif quand le point est **à droite** ($x>0$).
