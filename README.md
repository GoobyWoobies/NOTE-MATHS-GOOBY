# 📐 Mathématiques — Notes de cours (Analyse 1)

Bienvenue ! Ces notes reprennent le cours d'**Analyse 1** de façon claire, progressive et illustrée d'exemples.

## Comment est organisé le cours ?

| Partie | Contenu | Point d'entrée |
| --- | --- | --- |
| **Algèbre** | Les « outils de base » : nombres, symboles, puissances, racines, valeur absolue, équations et inéquations | [Algèbre](maths/Algebre/README.md) |
| **Analyse** | Les fonctions : définition, domaine, parité, puis la trigonométrie | [Analyse](maths/Analyse/README.md) |

## Comment lire ces pages ?

- 💡 **À retenir** : la règle essentielle, à connaître par cœur.
- ⚠️ **Attention** : une erreur classique à éviter.
- ✏️ **Exemple** : une application pas à pas.

> 🧭 **Conseil** : suis l'ordre du sommaire. Chaque chapitre s'appuie sur les précédents (l'algèbre sert dans toute l'analyse).

## Notation utilisée

Les formules sont écrites en LaTeX : $x^2 + y^2 = 1$ pour une formule dans le texte, et

$$\sin^2 \alpha + \cos^2 \alpha = 1$$

pour une formule mise en valeur.
